# 数据库初始化指南

## 📋 前置条件

在初始化数据库之前，请确保：

1. ✅ **已配置 `.env` 文件**
   - 数据库连接信息正确

2. ✅ **数据库服务正在运行**
   - MySQL 服务已启动
   - 可以正常连接

3. ✅ **已安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 初始化步骤

### 步骤一：创建数据库（如果不存在）

**方法一：自动创建（推荐）**

初始化脚本会自动检测并创建数据库，直接运行：

```bash
cd LangChain
python3 data_loader/init_db.py
```

**方法二：手动创建数据库**

如果需要单独创建数据库：

```bash
cd LangChain
python3 data_loader/create_database.py
```

**方法三：使用 MySQL 命令行**

```bash
mysql -u chenjiawei -p123456 -h 0.0.0.0 -P 3306
```

然后在 MySQL 中执行：

```sql
CREATE DATABASE IF NOT EXISTS `life_insurance` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 步骤二：导入数据

**方法一：使用初始化脚本（推荐，会自动创建数据库）**

```bash
cd LangChain

# 基本初始化（如果表已存在则跳过，如果数据库不存在会自动创建）
python3 data_loader/init_db.py
```

### 方法二：使用导入脚本

```bash
cd LangChain

# 基本导入
python3 data_loader/import_data.py

# 强制重新导入（会删除已存在的表）
python3 data_loader/import_data.py --force
```

### 方法三：强制重新初始化

如果需要重新导入所有数据（会删除现有表）：

```bash
cd LangChain

# 强制重新导入
python3 data_loader/init_db.py --force
```

## 📊 初始化过程

脚本会自动执行以下操作：

1. **扫描 SQL 文件**
   - 自动扫描 `../Data/` 目录下的所有 `.sql` 文件
   - 解析表结构信息

2. **检查表是否存在**
   - 检查数据库中是否已存在对应的表
   - 如果存在且未使用 `--force`，则跳过

3. **创建表并导入数据**
   - 执行 CREATE TABLE 语句创建表结构
   - 执行 INSERT INTO 语句导入数据

4. **显示统计信息**
   - 显示导入成功的表数量
   - 显示跳过的表数量
   - 显示失败的表和错误信息

## 🔧 常见问题

### Q1: 数据库连接失败

**错误信息：**
```
❌ 无法连接数据库: ...
```

**解决方法：**
1. 检查 `.env` 文件中的数据库配置
2. 确认数据库服务正在运行
3. 确认数据库用户有足够的权限
4. 检查防火墙设置

### Q2: 表已存在错误

**错误信息：**
```
⏭️  表 xxx 已存在，跳过导入
```

**解决方法：**
- 这是正常行为，如果表已存在会自动跳过
- 如果需要重新导入，使用 `--force` 参数：
  ```bash
  python3 data_loader/init_db.py --force
  ```

### Q3: SQL 语法错误

**错误信息：**
```
❌ 导入失败: SQL syntax error
```

**解决方法：**
1. 检查 SQL 文件格式是否正确
2. 确认数据库版本兼容性
3. 查看错误详情中的具体 SQL 语句

### Q4: 权限不足

**错误信息：**
```
❌ 权限不足: Access denied
```

**解决方法：**
1. 确认数据库用户有 CREATE、INSERT 权限
2. 检查数据库用户权限设置

# 配置说明

## 快速配置

### 1. 创建配置文件

```bash
# 方式一：复制示例文件
cp env.example .env

# 方式二：使用配置脚本
python config_env.py
```

### 2. 编辑 `.env` 文件

根据你的实际情况修改以下配置：

#### 数据库配置

```env
DB_HOST=0.0.0.0          # 数据库主机地址
DB_PORT=3306             # 数据库端口
DB_USER=your_db_user     # 数据库用户名
DB_PASSWORD=your_db_password  # 数据库密码
DB_NAME=life_insurance   # 数据库名称
```

#### 阿里云百炼模型配置

```env
# 请从阿里云控制台获取：https://dashscope.console.aliyun.com/apiKey
DASHSCOPE_API_KEY=sk-your-dashscope-api-key-here  # API密钥
MODEL_TYPE=api                                          # api 或 local
MODEL_NAME=qwen-turbo                                  # 模型名称
```

#### LLM 参数配置

```env
LLM_TEMPERATURE=0.1      # 温度参数 (0.0-1.0)
LLM_MAX_TOKENS=2000      # 最大生成 token 数
```

## 配置说明

### 数据库配置

- **DB_HOST**: 数据库服务器地址，可以是 IP 地址或域名
- **DB_PORT**: 数据库端口，MySQL 默认 3306
- **DB_USER**: 数据库用户名
- **DB_PASSWORD**: 数据库密码
- **DB_NAME**: 要连接的数据库名称

### 阿里云模型配置

- **DASHSCOPE_API_KEY**: 阿里云 DashScope API 密钥
  - 获取方式：登录阿里云控制台 -> 百炼平台 -> API-KEY管理
- **MODEL_TYPE**: 
  - `api`: 使用 API 调用（推荐）
  - `local`: 使用本地部署模型（需额外配置）
- **MODEL_NAME**: 模型名称
  - `qwen-turbo`: 快速响应，适合简单查询
  - `qwen-plus`: 平衡性能和效果
  - `qwen-max`: 最强性能，适合复杂查询

### LLM 参数配置

- **LLM_TEMPERATURE**: 控制输出的随机性
  - 0.0-0.3: 更确定、更一致的回答
  - 0.4-0.7: 平衡创造性和准确性
  - 0.8-1.0: 更随机、更有创造性的回答
- **LLM_MAX_TOKENS**: 限制生成的最大 token 数
  - 建议值：1000-4000
  - 注意：token 数越多，API 调用成本越高

## 常见问题

### Q: 如何获取阿里云 API Key？

A: 
1. 登录 [阿里云控制台](https://dashscope.console.aliyun.com/)
2. 进入"百炼平台"
3. 点击"API-KEY管理"
4. 创建新的 API Key 或使用现有 Key

### Q: 数据库连接失败怎么办？

A: 
1. 检查数据库服务是否启动
2. 确认 IP 地址、端口、用户名、密码是否正确
3. 检查防火墙设置
4. 确认数据库用户是否有远程连接权限

### Q: 如何切换不同的模型？

A: 修改 `.env` 文件中的 `MODEL_NAME` 参数即可，支持的值：
- `qwen-turbo`
- `qwen-plus`
- `qwen-max`

### Q: 配置修改后需要重启吗？

A: 是的，修改 `.env` 文件后需要重启应用程序才能生效。

## 安全提示

⚠️ **重要**：
- `.env` 文件包含敏感信息，已被 `.gitignore` 忽略
- 不要将 `.env` 文件提交到版本控制系统
- 不要在生产环境中使用默认密码
- 定期更换 API Key
